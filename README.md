# Lab_4

Тема  -  Реализация алгоритма сжатия текста.


Изначально есть файл с информацией (текстом) с кодами по таблице ASCII.

Алгоритм сжатия: Берется текущий символ. Побитово, начиная с младших разрядов, его биты записываются в старшие биты последующих символов
(7 последующих символов, так как старший бит и у текущего символа, и у последующих в ASCII не несут информации о символе(они у всех нули)).
Так до конца файла. Если в конце файла не хватает символов для записи битов текщего символа в их старшие биты, то все оставшиеся символы
записываются в сжатый файл без изменения.

Алгоритм расжатия: Берутся 7 символов и из них последовательно из старших разрядов извлекаются разряды для символа, который должен быть перед ними.
Заполнение этого символа идет с младших разрядов, а у считанных символов обнулятеся старший разряд.
Потом этот символ записывается в новый файл и 7 отсавшихся с обнуленными старшими битами после них. В конце проверяется случай, когда количество символов кратно 7,
и последние символы могли быть не изменены при сжатии информации (проверка идет есть ли 1 в старших битах, если все 0, то не изменялись)

С русскими символами программа будет выдавать мусор (часть данных при сжатии и расжатии будет потеряна)
