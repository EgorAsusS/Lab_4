# Lab_4

Тема  -  Реализация алгоритма сжатия текста.


Изначально есть файл с информацией (текстом) с кодами по таблице ASCII.

Алгоритм сжатия: Берется текущий символ. Побитово, начиная с младших разрядов, его биты записываются в старшие биты последующих символов
(7 последующих символов, так как старший бит и у текущего символа, и у последующих в ASCII не несут информации о символе(они у всех нули)).
Так до конца файла. Если в конце файла не хватает символов для записи битов текщего символа в их старшие биты, то все оставшиеся символы
записываются в сжатый файл без изменения (хвост).

Алгоритм расжатия: Берутся 7 символов и из них последовательно из старших разрядов извлекаются разряды для символа, который должен быть перед ними.
Заполнение этого символа идет с младших разрядов, а у считанных символов обнулятеся старший разряд.
Потом этот символ записывается в новый файл и 7 отсавшихся с обнуленными старшими битами после них. В конце проверяется случай, когда количество символов кратно 7,
и последние символы могли быть не изменены при сжатии информации (хвост) (проверка идет есть ли 1 в старших битах, если все 0, то не изменялись)

Если при сжатии встречаются русские символы, то файл созданный файл удаляется и возвращается ошибка

int compress(char* filepath, char* filepath_new);
На вход передаются пути к файлам какой файл сжимать и куда (в какой) файл сохранять (поддерживаются абсолютные и относительные пути)

int decompress(char* filepath, char* filepath_new);
На вход передаются пути к файлам какой файл сжимать и куда (в какой) файл сохранять (поддерживаются абсолютные и относительные пути)

Функции сжимают и расжимают файл по алгоритму описанному выше. Правильные данные - ASCII символы. Для decompress 1 символ в исходном файле '0' или '1'
(был ли хвост при кодировании или нет). Если не получается сжать файл, то новый файл удаляется

Коды возвращаемых значений для функций compress и decompress

Код | Описание ошибки
1   | Успешное сжатие/расжатие файла
0   | Нет файла или неверный путь к файлам, файл не открывается, не получилось сжать файл
-1  | Ошибка при закрытии файла
-2  | Ошибка при удалении файла
-3  | Неверные входные данные внутри файла
